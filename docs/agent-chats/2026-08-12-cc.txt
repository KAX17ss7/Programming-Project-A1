❯ Find what is controlling the dark mode theme of the web application.          

  Searched for 3 patterns, read 2 files (ctrl+o to expand)
  ⎿  Loaded frontend\CLAUDE.md

● Dark mode here is controlled entirely by the OS/browser's prefers-color-scheme
  — there's no theme toggle, no next-themes, and no dark class strategy in this
  codebase.

  How it works:

  1. frontend/src/app/globals.css (frontend\src\app\globals.css:15-20) — a media
  query flips two CSS custom properties (--background, --foreground) when the
  OS is in dark mode:
  @media (prefers-color-scheme: dark) {
    :root {
      --background: #0a0a0a;
      --foreground: #ededed;
    }
  }
  1. These feed body's background/color via the @theme inline block above it.
  2. Tailwind's dark: variant classes, used throughout components (e.g.
  frontend/src/app/page.tsx, frontend/src/app/(auth)/layout.tsx, Navbar,
  Sidebar, DashboardShell, etc.) — by default in Tailwind v4 these also key off
  prefers-color-scheme, not a .dark class.

  There's no JS-driven theme switcher (no next-themes, no ThemeProvider, no
  localStorage/cookie persistence, no toggle button) — the whole app just
  follows whatever the user's OS/browser is set to. If you want a manual
  light/dark toggle, that would need to be added (typically via next-themes + a
  dark class strategy).
